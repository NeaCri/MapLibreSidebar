This is a live demo of MapLibreSidebar — a minimal, reusable sidebar component for MapLibre GL JS projects.

Features

Click the icons on the left to switch between panes. Click the active icon again (or the ‹ close button) to collapse the sidebar.

Quick start

const sidebar = new MaplibreSidebar({
  container: '#sidebar',
  position: 'left',
  map: map,
  autopan: true
});
sidebar.open('home');
